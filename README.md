# JS & Node.js Learning Journal

This repo contains my hands-on practice exercises as I learn JavaScript and 
Node.js fundamentals from the ground up, on my way to building fullstack 
projects (MERN stack) for my internship portfolio.

Each folder covers one topic, with small exercises I wrote while learning 
that concept. This is a learning log, not a portfolio project — check my 
pinned repos for actual applications built using these fundamentals.
